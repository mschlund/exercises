\section*{Übungen}

\subsection*{1. Konvergenz von Reihen}
Untersuchen Sie, ob die folgenden Reihen konvergieren:
\begin{enumerate}
    \item[a)] $$\sum_{n=1}^\infty \frac{n!}{n^n}$$
    \item[b)] $$\sum_{n=2}^\infty \left( \frac{42}{\sqrt{n} \sqrt{n-1}} \right)$$
    \item[c)] $$\sum_{n=1}^\infty \frac{(-1)^n}{\ln{n}}$$
    \item[d)] $$\sum_{k=0}^\infty \frac{n^{2k+1}}{k!}$$
\end{enumerate}

\subsection*{2. Integration (I)}
Berechnen Sie das Integral:
\[
\int_0^2 \frac{x}{\sqrt{x^2 + 4}} \, dx
\]

\subsection*{3. Integration (II)}
Berechnen Sie das Integral:
\[
\int_0^1 \sin(x) e^x \, dx
\]

\subsection*{4. Grenzwert}
Bestimmen Sie den Grenzwert der Folge:
\[
a_n = \frac{\ln(n^3 + 5\cdot x^2 + x + 3)}{\sqrt{n} - \sqrt[3]{n}}
\]
